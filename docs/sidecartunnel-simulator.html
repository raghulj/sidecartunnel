02Grant matching, hands on

  
This is the single idea the whole design rests on. Your application returns a list of glob patterns; the gateway matches subscription requests against them as plain strings. It never learns what any segment means. Type a channel name and watch it resolve.

03The reconnect storm

  
The one operational risk this architecture creates that Pusher's does not: every new connection is a synchronous HTTP call into a request/response app with a fixed worker pool. Restart a gateway replica and every client comes back at once. Move the sliders.

A correction to something I said earlier: caching the connect response per session cookie does not protect against this. Five thousand reconnecting users are five thousand distinct cookies, so every one is a cache miss. The cache earns its place against multiple tabs, rapid flapping, and a single user's several devices — real, but secondary. Jittered backoff in the client and a concurrency cap in the gateway are the actual defenses, and the sliders show why: widening the jitter window is the single most effective control here.






  
04Frame reference

  
The complete client protocol. Nine message types, which is the whole surface a client implementation has to cover.

  

    
DirectionFrameMeaning

    
      
client →{"id":1,"connect":{}}First frame. Cookie already travelled in the HTTP upgrade.

      
← gateway{"id":1,"connect":{client,ping,expires_in}}Established. ping is the heartbeat interval in seconds.

      
client →{"id":2,"subscribe":{channel}}Join a channel. Matched against grants in memory.

      
← gateway{"id":2,"error":{code,message}}Refused. 103 is permission denied.

      
client →{"id":3,"unsubscribe":{channel}}Leave. Frees the upstream Redis subscription if last.

      
client →{"pub":{channel,data}}Ephemeral client event. Only where the namespace allows it.

      
← gateway{"push":{channel,pub}}A message. The only frame that carries application data inbound.

      
← gateway{"push":{refresh:true}}Grants near expiry — revalidate now.

      
← gateway{"disconnect":{code,reason,reconnect}}Closing. reconnect:false means do not retry.
